# Changelog

## 0.1.0 — 2026-10-08

First local production MVP for prepared Anchor migration projects.

- Generic Anchor/Borsh state decoding, fixtures, migration execution, preservation and lifecycle scenarios.
- Account relationship validation and exact expected-change policy approvals.
- Deterministic production workflow with CI exits 0–4 and JSON, HTML and Markdown evidence.
- Read-only Devnet import and frozen local replay; immutable native and portable full-workflow regression cases.
- Versioned manifests, locked atomic registry persistence, backup recovery and input resource limits.
- Compatibility fixtures for Anchor 0.30.1 and 1.2.0; seeded parser mutation and scale qualification.
- `doctor`, `--version`, `--help`, JSON, quiet and verbose diagnostics.
- Patched rustls 0.23.45, dependency audit, checksum release archive and standalone examples.

APIs, folder upload transport and frontend are the next product phase.
